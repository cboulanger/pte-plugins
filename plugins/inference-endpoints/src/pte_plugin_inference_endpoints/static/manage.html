Using a model on your own computer

Requests go from the server to the endpoint. localhost therefore means the machine (or container) the editor runs on.

  • Editor runs on your computer: use http://localhost:11434/v1. If the editor runs in Docker, use http://host.docker.internal:11434/v1 (on Linux, start the container with --add-host=host.docker.internal:host-gateway and let Ollama listen on all interfaces with OLLAMA_HOST=0.0.0.0).
  • Editor runs on a server: the server cannot reach your computer's localhost. Make Ollama reachable from the server, e.g. through a VPN such as Tailscale (http://my-laptop.tailnet-name.ts.net:11434/v1), an SSH reverse tunnel (ssh -R 11434:localhost:11434 server, then http://localhost:11434/v1), or a tunnel service. Ollama has no authentication; protect a publicly reachable tunnel with a key and enter it here.
  • Browser CORS settings such as OLLAMA_ORIGINS are not needed, since the browser never calls the endpoint.
